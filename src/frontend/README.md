# Frontend Service (Next.js)

This directory will host the React/Next.js frontend for the Human‑in‑the‑Loop dashboard.
- UI built with React 19, Tailwind CSS, shadcn/ui components.
- Data fetching via TanStack Query.
- Authentication & role‑based access for clinicians.

Initialize with:
```
npx create-next-app@latest . --typescript
npm install tailwindcss@latest postcss@latest autoprefixer@latest shadcn-ui
```
